# terraform-azure-infrastructure

This project is for provisioning a production-like Azure infrastructure using Terraform with reusable modules, remote state, and GitHub Actions CI/CD.

## Architecture

The infrastructure consists of:

- Virtual Network
- Virtual Machines
- Azure Storage Account
- Azure Key Vault
- Azure Monitor
- Log Analytics
- GitHub Actions CI/CD

## Technologies

- Terraform
- Microsoft Azure
- Git
- GitHub
- GitHub Actions

## Features

- Infrastructure as Code (IaC)
- Modular Terraform configuration
- Remote state backend
- Multi-environment deployment
- Secure secret management
- Monitoring and alerts
- Reusable modules
